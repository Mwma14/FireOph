# **App Name**: Operators Hub

## Core Features:

- Navbar Implementation: Implement a responsive navigation bar at the top of the page, for easy navigation.
- Hero Banner Design: Design and implement a hero banner section with the title 'Discover Operators Products' and a 'Buy Now' button, including animating operators sim card network indicator wave.
- Product Card Design: Design product cards to display product details, categorized under Data, Minutes, Points, Packages, and Beautiful Numbers for each operator.
- Dynamic Product Listing: Dynamically list each operator's products from a static JSON file, for easy updates and maintenance.
- Product Filtering: Implement filtering to narrow down displayed products by operator (MPT, OOREDOO (U9), ATOM, MYTEL) and product category (Data, Minutes, Points, Packages, Beautiful Numbers).

## Style Guidelines:

- Background: Dark grey (#121212) to support a dark mode aesthetic inspired by Binance's theme.
- Primary: Binance Yellow (#F0B90B) to convey energy and a futuristic feel.
- Accent: Orange (#FF9800) for interactive elements and highlights.
- Font: 'Space Grotesk', sans-serif, for both headlines and body text to achieve a minimal, techy feel. Note: currently only Google Fonts are supported.
- Use clean, simple line icons that are easily recognizable to convey a modern, tech-focused appearance.
- Maintain a clean and well-spaced layout using a grid system to organize content and provide structure. Ensure the design inspires users to scroll and explore the product details.
- Incorporate subtle, non-distracting transitions and animations to enhance user experience. Examples include a sim card network indicator wave animation in the hero section and card flip effects on hover.
